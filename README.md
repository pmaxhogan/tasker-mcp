# tasker-mcp docs data

This branch holds a scraped copy of the Tasker userguide
(https://tasker.joaoapps.com/userguide/en/), converted to Markdown with a
small search index. It is generated weekly by the docs-sync workflow and
is rewritten from scratch on every run.

The content is (c) joaoapps (Joao Dias). It is mirrored here only so the
tasker-mcp server can search it for its users, and it is not covered by
the MIT license of the tasker-mcp code. For the originals, see the source
URL at the top of each page.
