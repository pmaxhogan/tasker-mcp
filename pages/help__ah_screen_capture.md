# Screen Capture

Source: https://tasker.joaoapps.com/userguide/en/help/ah_screen_capture.html

Record the screen on your phone.

You can also optionally add sound to your recording. The sound will be captured from your Microphone.

Typical usage is:

- Use **Start** mode to begin recording in a task
- Use **Stop** mode to stop recording in a later task
- If yo need to check the current status of the recording use the **Query** mode
