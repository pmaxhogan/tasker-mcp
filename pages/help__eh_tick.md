# Tick

Source: https://tasker.joaoapps.com/userguide/en/help/eh_tick.html

[Watch a demo here](https://youtu.be/b3Lz9f30n88)

This event will simply automatically trigger with the time interval you specify, over and over again.

Combine it with some states if you only want it to trigger in certain situations.

If you need an interval larger than 2 minutes please use the **Time** condition instead.
