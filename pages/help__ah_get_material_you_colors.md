# Get Material You Colors

Source: https://tasker.joaoapps.com/userguide/en/help/ah_get_material_you_colors.html

Gets colors related to your current wallpaper on Android 12+

With this, you can create scenes and other UI using colors that match the rest of Android 12's UI.

Try using with the **Element Back Color** and **Element Text Color** actions for example to set the colors on your scenes.
