# Restart Tasker

Source: https://tasker.joaoapps.com/userguide/en/help/ah_restart_tasker.html

Works just like if you would manually open Tasker > Menu > Disable Tasker > Menu > Enable Tasker.

Could be useful if Tasker gets stuck in a task for example, for some reason and you want to make sure that you "unstick" it.
