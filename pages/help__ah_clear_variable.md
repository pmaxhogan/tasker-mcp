# Variable Clear

Source: https://tasker.joaoapps.com/userguide/en/help/ah_clear_variable.html

Remove the stored value for the user-variable Name.

If no **Name** is specified and the **Clear All Variables** option is selected, all user-variables are cleared.

If **Name** has a value the **Clear All Variables** option is ignored.

If Pattern Matching is specified, all variables which match the pattern are cleared (see Pattern Matching in the Userguide).
