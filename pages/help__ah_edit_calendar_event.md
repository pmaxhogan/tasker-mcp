# Edit Calendar Event

Source: https://tasker.joaoapps.com/userguide/en/help/ah_edit_calendar_event.html

This action lets you add, update, or delete events on your device's calendar.

Depending on the Calendar app you use, changes might not appear immediately. For instance, Google Calendar is known to have a delay. To update it quickly, try refreshing the calendar in the app twice.

When updating an event, only specified fields will be altered. For example, if you change just the **Description** but not the **Title**, the **Title** will remain unchanged in the Calendar while the **Description** will be updated.
