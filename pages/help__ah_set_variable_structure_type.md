# Set Variable Structure Type

Source: https://tasker.joaoapps.com/userguide/en/help/ah_set_variable_structure_type.html

Allows you to explicitely set the type of a variable's structure to JSON, XML, etc.

Read more about reading variables with structures [here](variables#json).

You usually don't need to use this since when you create a variable with a Tasker action (eg Variable Set) there's the **Structure Output** option that's enabled by default that does this for you.
