# Get Network Info

Source: https://tasker.joaoapps.com/userguide/en/help/ah_get_network_info.html

Gets network info about your device into Tasker variables.

You can either use one of the various specific variables that the action sets or use one of the generic "full_info" variables which will contain a [JSON structure](variables#json) of all the network info Tasker can get..
