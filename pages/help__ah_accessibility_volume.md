# Accessibility Volume

Source: https://tasker.joaoapps.com/userguide/en/help/ah_accessibility_volume.html

Allows you to set the media volume on some devices where the media volume is not supported.

Tasker's Accessibility Service needs to be running for this action to work. If Tasker has the WRITE_SECURE_SETTINGS permission it'll start the service on your behalf and stop it after the action if it was not running before.
