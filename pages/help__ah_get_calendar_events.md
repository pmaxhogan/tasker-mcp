# Get Calendar Events

Source: https://tasker.joaoapps.com/userguide/en/help/ah_get_calendar_events.html

This action allows you to get details on one or more events from your Calendar.

If you specify the Event ID, you'll only get 1 result back with its details. Otherwise you'll need to specify at least the start and end time to get all the events in that interval.

You can also filter the results by any other available field.
