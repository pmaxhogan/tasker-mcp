# Edit Calendar Attendee

Source: https://tasker.joaoapps.com/userguide/en/help/ah_edit_calendar_attendee.html

This action allows you to add, update or remove guests in a Calendar event.

To edit an attendee, you need to get the event's ID and use it in this action, and then set the other fields to appropriate values.

To get the event's ID, use the **Edit Calendar Event** (it'll be in a variable after you edit an event) or **Get Calendar Events** action.
