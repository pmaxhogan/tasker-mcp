# Text Dialog

Source: https://tasker.joaoapps.com/userguide/en/help/ah_dialog_text.html

Show a simple dialog with a title and some text in it. Optionally show up to 3 buttons that you can click.

The text on the button you clicked will be returned to you in the task in a local variable. Check the action's output variables for details.

If you cancel the dialog (click outside of it or press back on your device) the Tasker action will result in error and stop the task. You can make the task continue with the **Continue Task After Error** option.

Will not work simultaneously with non-overlay scenes.
