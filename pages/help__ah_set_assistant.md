# Set Assistant

Source: https://tasker.joaoapps.com/userguide/en/help/ah_set_assistant.html

Changes the app that handles the "Long Press Home Button" feature on most phones.

On some phones the assistant can also be called by saying "Ok Google" or by squeezing the device.

Check out the **Assisstance Request** event in Tasker so that Tasker can act as your assistant and completely customize your assistant experience.

Example [here](https://www.youtube.com/watch?v=OTLfQfeZRNQ).
