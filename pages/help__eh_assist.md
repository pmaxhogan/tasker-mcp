# Assistance Request

Source: https://tasker.joaoapps.com/userguide/en/help/eh_assist.html

The user has just requested assistance within the specified app.

On standard Android devices, this occurs when the user holds the bottom middle button of the display.

Some ROMs do not support specification of an App.

When setting Tasker as your assistant make sure to enable the **Use text from screen** option so that Tasker can get the necessary info to correctly trigger this event.

Check out an example of how to use this [here](https://www.youtube.com/watch?v=OTLfQfeZRNQ).
