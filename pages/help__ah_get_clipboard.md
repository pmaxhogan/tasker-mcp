# Get Clipboard

Source: https://tasker.joaoapps.com/userguide/en/help/ah_get_clipboard.html

Is able to get both text and image clipboard that's set on your device at a time.

Please note that usually only one or the other is set.

On Android 10+ you need special permissions for Tasker to be able to access your clipboard. Please follow the directions given by the app to enable these.
