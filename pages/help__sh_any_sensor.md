# Any Sensor State

Source: https://tasker.joaoapps.com/userguide/en/help/sh_any_sensor.html

Check how to configure **Any Sensor** conditions [here](help__any_sensor_base).

In this state you can directly select when the profile should be active by adding any number of conditions to the condition.

In these conditions you can use the %as_values() array values to only trigger the condition when really needed.

If you use the helper (magnifying glass) the conditions will be pre-populated for you.

If you want to trigger a task every time a certain sensor updates and don't want to set a condition use the **Any Sensor Event** instead.
