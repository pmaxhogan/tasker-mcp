# App Changed

Source: https://tasker.joaoapps.com/userguide/en/help/eh_app_changed.html

Will trigger whenever an app is opened (brought to the foreground).

If you need extra info on the app that was opened, use the **App Info** action in the entry task of the profile with the **Package** field set to **%app_package**.

Package

Optionally make this trigger only on selected apps.

If not set will trigger on all app changes.
