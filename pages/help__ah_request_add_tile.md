# Request Add Tile

Source: https://tasker.joaoapps.com/userguide/en/help/ah_request_add_tile.html

Allows you to show a dialog asking the user to add a Tasker quick setting tile to their existing quick setting tiles.

Note: the system can choose to auto-deny a request if the user has denied that specific request (user, ComponentName) enough times before. Android doesn't specify how many times this is.
