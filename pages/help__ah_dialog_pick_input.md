# Pick Input Dialog

Source: https://tasker.joaoapps.com/userguide/en/help/ah_dialog_pick_input.html

Allows you to easily pick a bunch of different types of input that you can then use in your task.

Will not work simultaneously with non-overlay scenes.

**Note:** When you add an action in a task you can use the search field in the dialog to search for one of the dialog types available here directly and then select the `Pick Input Dialog` action to have the type filled in automatically.
If you do this when adding a favorite action (long click the + button in task) you can have a direct shortcut to the specific type you searched for.

[Check out a demo for this here](https://www.youtube.com/watch?v=jjNlEYqN-Aw)

#### Data Formats

Each type of picker has a specific output format. These are the formats used for each one.

- **True Or False**: either **true** or **false**
- **Yes Or No**: either **yes** or **no**
- **File/Files/Directory**: path to the files/folder usable in other Tasker actions
- **Contact**: name of contact
- **Contact or Contact Group**: name of contact or contact group pattern used in compatible fields (like the Ringing or Call Screened event)
- **Time**: time it the HH.mm format
- **Date**: date in the yyyy-MM-dd format
- **App and Launcher**: an app's package name
