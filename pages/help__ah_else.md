# Else

Source: https://tasker.joaoapps.com/userguide/en/help/ah_else.html

Used after an If action to specify actions which should take place if the If condition didn't match.

An *Else* or *Else If* is skipped only if the block's *If* (or an earlier *Else If*) was evaluated and found true. If a *Goto* jumped into the block without going through its *If*, the *Else* runs (or, for *Else If*, its condition is checked) when the jumped-to branch ends.

See Flow Control in the Userguide for more info.
