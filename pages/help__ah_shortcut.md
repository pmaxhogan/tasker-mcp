# Shortcut

Source: https://tasker.joaoapps.com/userguide/en/help/ah_shortcut.html

Run an Android shortcut like the ones you can normally add to your launcher.

Use the magnifying glass to easily select a shortcut that you want to later run.

For now this action doesn't support some shortcuts that only work on the default launcher. In the future Tasker might have the ability to be a launcher itself so that it can support all kinds of shortcuts.
