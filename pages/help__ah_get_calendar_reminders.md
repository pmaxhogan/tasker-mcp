# Get Calendar Reminders

Source: https://tasker.joaoapps.com/userguide/en/help/ah_get_calendar_reminders.html

This action allows you to get details on one or more reminder of one of your Calendar events.

If you specify the Reminder ID, you'll only get 1 result back with its details.

If you set the Event ID, you'll get back all reminder for that event.

If you set the Calendar Name, you'll get back all reminder for that Calendar.
