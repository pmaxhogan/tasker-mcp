# Notification Removed

Source: https://tasker.joaoapps.com/userguide/en/help/eh_notification_removed.html

A notification has been removed from the status bar.

If an Owner Application is specified, the notification must have been sent by the corresponding package.

Other Text (Android 6+) is a collection of any other texts found in the notification.

This event is not triggered by this apps own generated notifications. To clarify, Tasker notifications will not trigger this event in Tasker and Kid App notifications will not trigger this event in those apps.
