# Remote Action Token Changed

Source: https://tasker.joaoapps.com/userguide/en/help/eh_remote_action_token_changed.html

This event will trigger when the token for Remote Actions on this device changes.

You can use this event to send the updated token somewhere (like Dropbox, Google Drive, etc) where other devices can get it so they can execute remote actions on this device.

You can also use the **Remote Action Execution** action to get this token at any time.
