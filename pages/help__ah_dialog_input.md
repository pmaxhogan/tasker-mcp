# Input Dialog

Source: https://tasker.joaoapps.com/userguide/en/help/ah_dialog_input.html

Get some text from the user and use it in the task for whatever you want.

The text you in get from the dialog will be available in the **%input** variable.

Will not work simultaneously with non-overlay scenes.

Input Type

To easily select the input type use the **Magnifying Glass** button next to it.

Use HTML

If enabled, you can use HTML tags to format the dialog's title and text.

Not all HTML tags are supported. Check [here](https://stackoverflow.com/a/45146556/1002963) to see which ones are.
