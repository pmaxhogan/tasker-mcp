# Test Display

Source: https://tasker.joaoapps.com/userguide/en/help/ah_test_display.html

Test an attribute of the display.

- **AutoRotate**: on or off
- **Orientation**: portrait or landscape.
- **Resolution/DPI**: depends on current orientation of display.
- **Is Locked**: true if the display is locked (securely or insecurely) or false if the display is unlocked
- **Is Securely Locked**: true if the display is securily locked (you have to input some kind of credentials to unlock it) or false if the display is unlocked
- **Display Density**: a multiplier that you can apply to a number in dpi (dots per inch) to get the number of corresponding pixels.
- **Navigation Bar Height**: the height of the navigation bar on your device in pixels.
- **Navigation Bar Top Offset**: the number of pixels a scene has to be offset vertically for it to display over the navigation bar, starting from its top.
- **Navigation Bar Center Offset**: the number of pixels a scene has to be offset vertically for it to display over the navigation bar, starting from its center.
- **Status Bar Offset**: the number of pixels a scene has to be offset vertically for it to display over the status bar, starting from its top.
