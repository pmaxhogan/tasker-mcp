# Get Sunrise/Sunset Times

Source: https://tasker.joaoapps.com/userguide/en/help/ah_get_sunrise_sunset.html

Will return several variables related to the sun position.

All time related variables will be in **Seconds since Epoch**.

You can format the returned time variables into any format with the **Parse/Format DateTime** action, setting **Input Type** to **Seconds Since Epoch** and then setting the input to one or more time related variables returned by this action.
