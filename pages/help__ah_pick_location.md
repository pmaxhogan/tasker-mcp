# Pick Location

Source: https://tasker.joaoapps.com/userguide/en/help/ah_pick_location.html

Pick a location on a map.

You'll get the selected location back in your task in the various Output Variables.

Select Radius

If enabled, the **%pl_radius** will have your selected radius in meters.

Initial Location

If set, the map will be centered on that location when it first shows. If not, map will be centered on your current location.
