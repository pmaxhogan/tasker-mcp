# Edit Calendar Reminder

Source: https://tasker.joaoapps.com/userguide/en/help/ah_edit_calendar_reminder.html

This action allows you to add, update or remove notification or email reminders in a Calendar event.

To edit a reminder, you need to get the event's ID and use it in this action, and then set the other fields to appropriate values.

To get the event's ID, use the **Edit Calendar Event** (it'll be in a variable after you edit an event) or **Get Calendar Events** action.
