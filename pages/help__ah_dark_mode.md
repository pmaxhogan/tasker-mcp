# Dark Mode

Source: https://tasker.joaoapps.com/userguide/en/help/ah_dark_mode.html

For Android 10+ devices.

Also works on some Android 9+ devices, but only reliably works on Android 10+.

Allows you to toggle the system wide Dark Mode on your device.

For examples on how to use Dark Mode with Tasker check out this [example Tasker Project](https://taskernet.com/shares/?user=AS35m8ne7oO4s%2BaDx%2FwlzjdFTfVMWstg1ay5AkpiNdrLoSXEZdFfw1IpXiyJCVLNW0yn&id=Project%3ADark+Mode).
