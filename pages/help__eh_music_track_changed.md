# Music Track Changed

Source: https://tasker.joaoapps.com/userguide/en/help/eh_music_track_changed.html

Will trigger whenever Tasker detects that a different song is playing.

This is based solely on media notifications.

It will not work if the media app you use doesn't add media info to their notifications. If this is the case, please ask their app developers to add the info so Tasker and other apps can intercept it.
