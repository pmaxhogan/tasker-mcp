# Power Menu Shown (Android 11+)

Source: https://tasker.joaoapps.com/userguide/en/help/eh_power_menu_shown.html

This will trigger when:

- You long press the power button and at least 1 Tasker tile is present (**%pms_add_controls** will be set to **false**). If you update a tile in reaction to this screen with the **Power Menu Action** action in Tasker it'll interactively update on the screen.
- The full list of Tasker tiles is shown after selecting the "Add controls" option in the Power Menu (**%pms_add_controls** will be set to **true**). If you update a tile in reaction to this screen, it'll only update the next time the screen is shown.
