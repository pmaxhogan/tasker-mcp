# Set SMS App

Source: https://tasker.joaoapps.com/userguide/en/help/ah_set_sms_app.html

Set the app which is the system-default SMS app.

If you grant Tasker permission to [write secure settings](help__ah_secure_setting_grant) this will be set without a prompt, otherwise a dialog will be shown to confirm the change.

Will have no effect unless a valid app is chosen.

**Imporant Note:** Because of internal Android changes this action may not work without the prompt on Android 11+. Unfortunately there's nothing Tasker can do to change that.
